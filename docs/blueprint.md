# **App Name**: The Hunch

## Core Features:

- Start Game: Game setup: Allow a player to start a game and assign a game master.
- Join Game: Joining a game: Enable other players to join the game upon approval by the initial player.
- Screen Name: Screen name: Allow players to enter a screen name to play under.
- Game Structure UI: Game Day Display: Display 7 playing days, 4 rounds for each day, and an endgame.
- Objectives Display: Display for winning objectives.
- Win Lives: Gameplay Mechanics: Implement winning ‘lives’ for the end game.
- Win Daily Coins: Gameplay Mechanics: Implement daily coins system.

## Style Guidelines:

- Primary color: Vivid purple (#BE29EC) to convey intuition, mystery and anticipation.
- Background color: Very light desaturated purple (#F1E5F7) to support the vibrant primary color.
- Accent color: Blue-violet (#5B30E8) to highlight interactive elements.
- Body and headline font: 'Inter', sans-serif. Contemporary style will fit well with an intuitive theme, while maintaining easy legibility for all text sizes. 
- Use abstract, slightly blurred icons to represent the uncertain nature of "hunches" and predictions.
- Use a fluid, modern layout with rounded corners and subtle shadows to create a soft and approachable user experience.
- Incorporate subtle animations (e.g., a pulsing glow, a shimmering effect, or a flowing gradient) to signal "hunches" or potential outcomes. The effect should be understated.
